## ✦ Sobre o projeto

O **First to the Key** é um jogo educativo criado como ferramenta de apoio ao estudo de conteúdos fundamentais da área da computação. A proposta é unir elementos de gamificação ao aprendizado, para que estudar seja mais leve e didático.

O projeto foi desenvolvido na disciplina de **Introdução à Ciência da Computação**, no primeiro semestre do curso de Ciência da Computação da **UNIVASF**, **com o auxílio de ferramentas de IA** durante o desenvolvimento.

<br/>

## ✦ Tecnologias

- **HTML** para a estrutura da página
- **CSS** para o visual e a interface
- **JavaScript** para a lógica do jogo

O jogo roda direto no navegador, sem instalação e sem servidor.

<br/>

## ✦ Como executar

**Online:** acesse o link do botão "Jogar online", no topo da página.

**Localmente:**

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/Gabrielle206/First-to-the-key.git
   ```
2. Abra a pasta do projeto.
3. Dê dois cliques no arquivo `index.html` para abrir no navegador.

> Se o som não tocar de início, clique em qualquer lugar da página. Alguns navegadores bloqueiam o áudio até a primeira interação.
